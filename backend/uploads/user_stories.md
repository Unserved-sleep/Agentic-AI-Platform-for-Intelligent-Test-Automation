# User Stories

## As a Customer
- **US-01:** As a customer, I want to upload my medical bills via the mobile app so that I can initiate a reimbursement claim without visiting a branch.
- **US-02:** As a customer, I want to track the status of my claim in real-time so that I know when to expect the payout.

## As an Underwriter
- **US-03:** As an underwriter, I want to view a centralized dashboard of customer risk profiles so that I can approve or reject policies faster.
- **US-04:** As an underwriter, I want the system to flag applications with pre-existing diseases automatically for manual review.

## As an Admin
- **US-05:** As an admin, I want to add new insurance products (like EV Motor Insurance) to the catalog easily.
